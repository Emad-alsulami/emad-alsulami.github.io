# 🌱 مهارات الحي · Nearby Skills

منصة لتبادل المهارات بين الجيران: علّم اللي تعرفه وتعلّم من جيرانك، بدون فلوس.
مثال: «أعلّمك الخط العربي مقابل إنك تصلّح دراجتي».

**A neighbourhood skill-swap web app.** Teach what you know, learn from the people next door, no money involved.

---

## ✨ المميزات

| الصفحة | وش فيها |
|---|---|
| **القريب** | عدد المهارات في حيّك، مهام اليوم مع مؤشر الإنجاز، شرح "كيف يشتغل التبادل"، بحث وفلترة حسب النوع (عرض/طلب) والتصنيف |
| **الرسائل** | قائمة محادثات مع بحث وفلاتر (غير مقروءة، طلبات، مواعيد، عروض)، بطاقة الموعد القادم، إرسال رسائل مع رد تجريبي تلقائي |
| **مهاراتي** | الملف الشخصي والإحصائيات، عروضك النشطة، قبول ورفض الطلبات، المواعيد القادمة، التبادلات المكتملة والتقييمات |

- 🌍 **لغتين:** العربية (من اليمين لليسار) والإنجليزية، بزر تبديل واحد
- 📱 **متجاوب:** شريط تنقل سفلي على الجوال، وتخطيط بعمودين على الكمبيوتر
- ➕ **إضافة مهارة:** نموذج كامل (عرض أو طلب، العنوان، التصنيف، الوصف، المقابل)
- 💾 **حفظ تلقائي:** كل التغييرات تنحفظ في المتصفح (localStorage)
- ♿ **سهولة الوصول:** تنقل بلوحة المفاتيح، نوافذ منبثقة يمكن الوصول إليها، ودعم إعداد تقليل الحركة
- ⚡ **بدون أي مكتبات أو بناء:** HTML و CSS و JavaScript فقط

## 🚀 النشر على GitHub Pages (مجانًا)

1. سجّل دخولك في [github.com](https://github.com)، واضغط **+** ثم **New repository**.
2. سمّه مثلًا `nearby-skills`، واختر **Public**، ثم **Create repository**.
3. في صفحة المستودع اضغط **uploading an existing file**، واسحب **كل محتويات** مجلد `nearby-skills` (وليس المجلد نفسه)، ثم **Commit changes**.
4. افتح **Settings ← Pages**.
5. تحت **Build and deployment** اختر **Source: Deploy from a branch**، والفرع **main** والمجلد **/ (root)**، ثم **Save**.
6. انتظر دقيقة أو دقيقتين، وموقعك بيكون على:
   `https://<اسم-حسابك>.github.io/nearby-skills/`

### أو من سطر الأوامر

```bash
cd nearby-skills
git init
git add .
git commit -m "Initial commit: Nearby Skills"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/nearby-skills.git
git push -u origin main
```

بعدها فعّل Pages من الإعدادات كما في الخطوتين 4 و5.

## 🛠️ التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا بسيطًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## 🎨 التخصيص

- **الألوان:** المتغيرات في أعلى `css/styles.css` (`--g700` هو الأخضر الأساسي)
- **النصوص:** `js/i18n.js`
- **العروض والجيران والمحادثات:** `js/data.js`
- **إعادة البيانات للوضع الأصلي:** زر «إعادة ضبط البيانات التجريبية» أسفل الصفحة

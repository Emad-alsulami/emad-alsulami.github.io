# نانو (Nano)

وكيل ذكي ومستشار شخصي للعصف الذهني والتخطيط وحل المشكلات، يتكلم باللهجة السعودية.

## الأدوات

| الأداة | وش تسوي | تحتاج إعداد؟ |
|---|---|---|
| 🔎 `web_search` | بحث في الإنترنت عن معلومات حديثة (Tavily) | لا، يشتغل بالوضع المجاني المحدود. ولرفع الحد أضف `TAVILY_API_KEY` |
| 📄 `fetch_url` | يقرأ صفحة ويب من رابط | لا |
| 🧮 `calculate` | حاسبة دقيقة وآمنة | لا |
| 🧠 `remember` / `forget` | ذاكرة طويلة عن المستخدم | للمسجلين فقط (D1) |
| 🖼️ الصور | يفهم الصور المرفقة (Llama 4 Vision) | لا |

النموذج يقرر بنفسه متى يستخدم الأداة. كل رد يقدر يستخدم لين 3 جولات أدوات، ويظهر فوق الرد وش الأدوات اللي استخدمها، مع روابط المصادر.

- **الواجهة:** GitHub Pages ← `https://emad-alsulami.github.io/nano/`
- **العقل:** Cloudflare Worker + Workers AI (نموذج مفتوح المصدر `Llama 4 Scout`)
- **الحسابات والمزامنة:** Cloudflare D1 (اختياري)
- **التكلفة:** مجاني ضمن 10,000 neuron يومياً (يتجدد 3 الفجر بتوقيت السعودية)

```
المتصفح  ──►  Cloudflare Worker (فيه شخصية نانو)  ──►  Workers AI (Llama)
                       │
                       └──►  D1 (الحسابات والمحادثات)
```

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | واجهة المحادثة |
| `app.js` | منطق المحادثة والحفظ في المتصفح |
| `config.js` | رابط الـ Worker (**الشي الوحيد اللي تعدله**) |
| `worker/worker.js` | كود الـ Worker: شخصية نانو + الحسابات + المزامنة |

## التشغيل (مرة وحدة، تقريباً 5 دقايق)

1. **سجّل في Cloudflare** مجاناً: <https://dash.cloudflare.com/sign-up>
2. **أنشئ Worker:** من القائمة **Compute (Workers)** ← **Workers & Pages** ← **Create** ← **Start with Hello World** ← سمّه `nano` ← **Deploy**.
3. **الصق الكود:** اضغط **Edit code**، امسح الموجود، والصق محتوى `worker/worker.js` كامل ← **Deploy**.
4. **اربط الذكاء الاصطناعي:** ارجع لصفحة الـ Worker ← **Settings** ← **Bindings** ← **Add** ← **Workers AI** ← اسم المتغير: `AI` ← **Deploy**.
5. **انسخ رابط الـ Worker** (شكله `https://nano.xxxx.workers.dev`) وافتحه في المتصفح؛ لازم يطلع لك `نانو شغال ✅`.
6. **حط الرابط في `config.js`:**
   ```js
   window.NANO_CONFIG = { WORKER_URL: "https://nano.xxxx.workers.dev" };
   ```
   واعمل commit. بعد دقيقة تقريباً يشتغل الموقع.

## تفعيل الحسابات ومزامنة المحادثات (D1)

بدون هالخطوة نانو يشتغل عادي، والمحادثات تنحفظ في المتصفح بس.

1. من القائمة: **Storage & Databases** ← **D1 SQL Database** ← **Create Database** ← سمّها `nano-db` ← **Create**.
2. افتح الـ Worker `nano` ← **Settings** ← **Bindings** ← **Add binding** ← **D1 database** ← اسم المتغير: `DB` ← اختر `nano-db` ← **Add Binding**.
3. تأكد إن كود الـ Worker هو آخر نسخة من `worker/worker.js` ← **Deploy**.
4. افتح رابط الـ Worker؛ لازم يطلع `database: مربوطة ✅`.

الجداول تنشأ تلقائياً أول ما أحد يسجّل، ما تحتاج تكتب SQL.

**الأمان:**
- كلمات المرور تنحفظ مشفّرة (PBKDF2-SHA256، 100,000 دورة، salt لكل مستخدم)، ما أحد يقدر يقرأها حتى أنت.
- جلسة الدخول تدوم 90 يوم، والسيرفر يحفظ hash للتوكن بس.
- بعد 8 محاولات دخول غلط خلال 15 دقيقة، الحساب يتقفل مؤقتاً.
- كل مستخدم يشوف محادثاته هو بس.
- لما تسجّل خروج، تنمسح نسخة المحادثات من المتصفح (مفيد لو الجهاز مشترك).

## رفع حد البحث (اختياري)

1. سجّل مجاناً في <https://app.tavily.com> وانسخ الـ API key (يبدأ بـ `tvly-`).
2. في الـ Worker: **Settings** ← **Variables and Secrets** ← **Add** ← النوع **Secret** ← الاسم `TAVILY_API_KEY` ← الصق المفتاح ← **Deploy**.

## التخصيص

- **تغيير الشخصية:** عدّل `SYSTEM_PROMPT` في الـ Worker من لوحة Cloudflare ثم Deploy (الموقع ما يحتاج تعديل).
- **تغيير النموذج:** عدّل `MODEL` في الـ Worker. بدائل تستاهل التجربة:
  - `@cf/meta/llama-3.3-70b-instruct-fp8-fast` (أقوى، لكن يستهلك الحد المجاني أسرع)
  - `@cf/qwen/qwen3-30b-a3b-fp8`
  - القائمة الكاملة: <https://developers.cloudflare.com/workers-ai/models/>
- **التجربة محلياً:** شغّل `python3 -m http.server 8000` داخل مجلد الـ repo وافتح `http://localhost:8000/nano/`.

## ملاحظات

- بدون تسجيل دخول: المحادثات في المتصفح فقط (localStorage). مع تسجيل الدخول: تتزامن عبر D1 بين كل أجهزتك.
- الـ Worker يقبل الطلبات من `emad-alsulami.github.io` والـ localhost فقط (`ALLOWED_ORIGINS`)، وهذا يقلل الاستخدام العشوائي لكنه مو حماية كاملة.
- يرسل آخر 20 رسالة فقط للنموذج عشان يوفّر الحد المجاني.
